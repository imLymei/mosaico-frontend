# Mosaico Frontend

Mosaico is a vault system for storing and managing passwords within images. This frontend provides a Single Page Application (SPA) built with vanilla HTML, CSS, and JavaScript for user authentication, vault management, file upload/download, and steganography encryption.

[Português (BR)](README.pt-BR.md)

## Requirements

- A modern web browser (Chrome, Firefox, Edge, etc.)
- The Mosaico backend running at `http://localhost:5000`

## Installation

No installation or build step required. Simply open the HTML file directly in your browser.

**Linux / Mac:**
```bash
xdg-open index.html
# or
open index.html
```

**Windows (Command Prompt):**
```cmd
start index.html
```

**Windows (PowerShell):**
```powershell
Start-Process index.html
```

## Usage

1. Start the backend server (`http://localhost:5000`)
2. Open `index.html` in your browser
3. Register or login to access your vaults
