# Mosaico Frontend

Mosaico é um sistema de cofre para armazenar e gerenciar senhas dentro de imagens. Este frontend fornece uma Single Page Application (SPA) construída com HTML, CSS e JavaScript puro para autenticação de usuários, gerenciamento de cofres, upload/download de arquivos e criptografia por esteganografia.

[English](README.md)

## Requisitos

- Um navegador web moderno (Chrome, Firefox, Edge, etc.)
- O backend do Mosaico rodando em `http://localhost:5000`

## Instalação

Nenhuma instalação ou etapa de build necessária. Basta abrir o arquivo HTML diretamente no seu navegador.

**Linux / Mac:**
```bash
xdg-open index.html
# ou
open index.html
```

**Windows (Prompt de Comando):**
```cmd
start index.html
```

**Windows (PowerShell):**
```powershell
Start-Process index.html
```

## Uso

1. Inicie o servidor backend (`http://localhost:5000`)
2. Abra `index.html` no seu navegador
3. Cadastre-se ou faça login para acessar seus cofres
